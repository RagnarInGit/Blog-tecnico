# Blog Técnico

## Contexto del problema

Durante una actividad práctica desarrollé un dashboard en Excel para analizar ventas mediante tablas dinámicas, segmentadores y KPIs.

## Descripción del desafío

El principal desafío técnico fue configurar correctamente las tablas dinámicas para que los segmentadores filtraran toda la información y lograr que los indicadores mostraran resultados correctos.

Además, aparecieron errores al crear fórmulas, celdas con numerales (####) y dificultades para organizar el dashboard.

## Acciones tomadas

Primero revisé la estructura de los datos.

Luego construí nuevamente los KPIs desde cero.

Configuré correctamente los segmentadores.

Ajusté el ancho de las columnas para solucionar el problema de los numerales.

Probé cada indicador hasta verificar que mostrara los valores esperados.

Finalmente organicé el dashboard para facilitar su lectura.

## Lecciones aprendidas

Aprendí que antes de crear indicadores es importante tener una buena estructura de datos.

También comprendí la importancia de validar cada cambio antes de continuar.

La documentación del proceso facilita detectar errores y mejorar futuras implementaciones.

Reforce conocimientos y puse en practica otros que si tenia en cuenta

## Evidencia del control de versiones

Todos los cambios fueron registrados mediante commits en este repositorio.

## Reflexión sobre feedback radicalmente sincero

Durante el desarrollo recibí observaciones sobre errores en la configuración de las tablas dinámicas y los KPIs.

En lugar de continuar sobre una base incorrecta, acepté el feedback y reconstruí parte del trabajo desde cero.

Esto permitió obtener un resultado mucho más claro y correcto.

Hubo pruebas antes de publicar el resultado final.
